# 디스코드 통계/포인트 봇

음성·채팅 활동 집계, 신규 멤버 안내 자동화, 반응 역할, 포인트 상점 기능을 갖춘 디스코드 봇입니다.

## 기능 요약

| 명령어 | 설명 |
|---|---|
| `/음성 [유저]` | 음성 누적 시간을 이미지 카드로 표시 (순위 포함) |
| `/채팅 [유저]` | 채팅 누적 횟수를 이미지 카드로 표시 (순위 포함) |
| `/음성순위`, `/채팅순위` | 서버 TOP 10 순위 |
| `/포인트 [유저]` | 누적 포인트 확인 |
| `/추가`, `/제거` | (관리자) 포인트 지급/차감 |
| `/온보딩설정` | `!안내`에서 사용할 역할/로그채널 설정 |
| `!안내 @유저 남자/여자 출생년도 경로` | 뉴페이스/기본/성별/연령대 역할 자동 지급, 미인증 역할 제거, 로그 전송 |
| `!이름 @유저 이름` | 닉네임을 `『 신입 』이름` 형식으로 변경 |
| `/메세지`, `/역할추가` | 임베드 메세지 전송 + 반응 역할 연결 |
| `/상점역할`, `/상점메세지` | 카테고리 드롭다운 방식 포인트 상점 |
| `/상점초기화` | (관리자) 상점에 등록된 역할 전체 삭제 (확인 버튼 포함) |
| `/랭크설정`, `/랭크제거`, `/랭크목록` | (관리자) 포인트 랭크 단계 등록/삭제/조회 |
| `/랭크 [유저]` | 현재 랭크와 다음 랭크까지 남은 포인트 확인 |
| `/랭크순위` | 포인트 기준 랭크 순위 TOP 10 |
| `/음성포인트설정`, `/음성포인트제거`, `/음성포인트목록` | (관리자) 특정 카테고리의 음성채널만 다른 포인트 요율 적용 |
| `/가챠포인트 [유저]` | 가챠(도박) 전용 포인트 확인 |
| `/포인트전환`, `/가챠전환` | 포인트 ↔ 가챠포인트 상호 전환 |
| `/가챠추가`, `/가챠제거` | (관리자) 가챠포인트 지급/차감 |
| `/야바위`, `/홀짝`, `/동전던지기`, `/ox`, `/가위바위보`, `/돌림판`, `/경마시작`, `/경마배팅`, `/몰아주기시작`, `/몰아주기참여` | 가챠포인트로 즐기는 미니게임 |
| `/포인트선물` | 다른 유저에게 포인트(일반)를 선물 |

포인트 환산: **음성 5분 = 100포인트**, **채팅 1회 = 1포인트**

## 1. 사전 준비

1. https://discord.com/developers/applications 에서 애플리케이션/봇 생성 후 토큰 발급
2. Bot 설정에서 아래 인텐트를 반드시 켜주세요.
   - `SERVER MEMBERS INTENT`
   - `MESSAGE CONTENT INTENT`
3. OAuth2 > URL Generator에서 `bot`, `applications.commands` 스코프 선택 후, 권한은 최소
   `역할 관리`, `닉네임 관리`, `메세지 보내기`, `임베드 링크`, `반응 추가`, `메세지 기록 보기`
   를 체크해 초대 링크를 만들고 서버에 초대하세요.
4. **봇 역할 순서**: 서버 역할 목록에서 봇 역할을 자동 지급/회수할 모든 역할보다 위쪽에 두어야
   역할 지급/제거가 정상 동작합니다.

## 2. 로컬 실행

```bash
pip install -r requirements.txt
cp .env.example .env   # 이후 .env에 DISCORD_TOKEN 입력
python main.py
```

한글이 카드 이미지에 정상 표시되도록 `assets/fonts/README.txt` 안내에 따라
`NotoSansKR-Bold.ttf`, `NotoSansKR-Regular.ttf` 파일을 넣어주세요. (필수)

## 3. 최초 설정 순서 (서버에서)

1. `/온보딩설정` — 미인증역할, 뉴페이스역할, 기본역할, 남자/여자역할, 10대~40대이상 역할,
   안내로그채널을 지정 (한 번에 다 넣지 않아도 되며, 여러 번 실행해 하나씩 채워도 됩니다)
2. `!안내 @유저 여자 2001 오픈채팅` 형식으로 신규 멤버 안내
3. `/상점역할 역할:@VIP 포인트:500 카테고리:데코레이션` 으로 상점에 역할 등록
   (카테고리를 생략하면 자동으로 "기타"에 들어갑니다. 같은 카테고리 이름으로 여러 역할을 등록하면
   한 카테고리 안에 묶여서 표시됩니다)
4. `/상점메세지 채널:#상점 제목:포인트샵 내용:원하는역할을 구매하세요` 로 카테고리 선택 드롭다운이
   있는 메세지 전송 → 유저가 카테고리를 선택하면 그 안의 역할 목록이 본인만 보이는 창으로 뜨고,
   역할을 선택하면 바로 구매(포인트 차감 + 역할 지급)됩니다.
5. 등록된 상품을 전부 지우고 싶다면 `/상점초기화` 실행 후 확인 버튼을 눌러주세요.

## 랭크 시스템

`/랭크설정 이름:랭크1 필요포인트:1000` 처럼 포인트 구간별로 랭크를 등록하면, 유저가 그 포인트에
도달했을 때 `/랭크`에서 해당 랭크 이름이 표시됩니다. `역할` 옵션을 함께 주면 그 포인트에 도달하는
순간 디스코드 역할도 자동으로 지급되고, 다음 랭크로 올라가면 이전 랭크 역할은 자동으로 회수됩니다
(역할을 지정하지 않으면 화면 표시용으로만 쓰입니다).

- `/랭크설정`, `/랭크제거`, `/랭크목록` — 관리자용 랭크 단계 관리
- `/랭크 [유저]` — 현재 랭크, 포인트, 다음 랭크까지 남은 포인트 확인
- `/랭크순위` — 포인트 기준 서버 TOP 10과 각자의 랭크 이름 표시

## 카테고리별 음성 포인트 요율

기본적으로 음성은 5분당 100포인트가 지급되지만, 특정 카테고리(예: "니트로 부스터 전용" 같은
음성채널 묶음)만 다른 포인트를 주고 싶다면:

```
/음성포인트설정 카테고리:@스트리밍 포인트당5분:200
```

이렇게 설정하면 그 카테고리 밑에 있는 음성채널에 있을 때만 5분당 200포인트가 지급되고,
다른 카테고리는 기존처럼 5분당 100포인트가 그대로 적용됩니다. 여러 카테고리에 각각 다른
요율을 설정할 수 있고, `/음성포인트제거`로 개별 설정을 지우면 기본 요율로 돌아갑니다.
`/음성포인트목록`으로 현재 설정을 한눈에 확인할 수 있습니다.

유저가 채널을 이동하거나 나가는 시점에 그동안 있었던 채널의 카테고리 요율이 정산되므로,
설정을 바꾼 시점 이후의 활동부터 새 요율이 적용됩니다.

## 가챠포인트 & 미니게임

일반 `포인트`(음성/채팅으로 쌓이는 것)와 `가챠포인트`는 완전히 분리된 별도의 화폐입니다.
도박성 미니게임은 오직 가챠포인트로만 즐길 수 있어서, 게임에서 잃어도 상점에서 쓰는
포인트에는 영향이 없습니다.

- `/포인트전환 포인트:10` → 10P를 가챠포인트 100으로 전환 (10 단위로만 가능)
- `/가챠전환 가챠포인트:100` → 가챠포인트 100을 10P로 전환 (100 단위로만 가능)
- `/가챠포인트 [유저]` → 가챠포인트 잔액 확인
- `/가챠추가`, `/가챠제거` → 관리자가 가챠포인트를 직접 지급/차감

전환 비율과 최대 배팅 한도는 `config.py`의 `GAMBLING_MAX_BET`, `GAMBLING_POOL_MAX_BET`,
`POINT_TO_GACHA_RATE`, `GACHA_TO_POINT_RATE` 값을 바꿔서 조정할 수 있습니다.

미니게임 목록: `/야바위`, `/홀짝`, `/동전던지기`(플립 애니메이션), `/ox`,
`/가위바위보`(다른 유저에게 도전 → 상대가 **[참여]** 버튼을 눌러야 시작, 그 후 각자
가위/바위/보를 비공개로 선택), `/돌림판`(회전 애니메이션, 최대 배팅 상향),
`/경마시작`+`/경마배팅`(채널당 30초 배팅 후 자동 진행, 참여할 때마다 안내 메세지에
참여자 명단이 실시간으로 갱신되고 레이스 자체도 트랙 애니메이션으로 진행),
`/몰아주기시작`+`/몰아주기참여`(참가자들이 배팅한 금액을 한 명이 몰아서 가져가며,
참여할 때마다 안내 메세지에 참여자 명단이 실시간으로 갱신됨).

배팅 상한: 야바위/홀짝/동전던지기/ox/가위바위보는 `GAMBLING_MAX_BET`(기본 1,000),
돌림판은 `WHEEL_MAX_BET`(기본 10,000), 몰아주기는 `GAMBLING_POOL_MAX_BET`(기본 5,000)
— 모두 `config.py`에서 조정 가능합니다.

## 랭크 기준

랭크는 오직 **"포인트"**(음성/채팅 활동, `/추가`·`/제거`, `/포인트선물`, `/가챠전환`으로
증감하는 그 포인트) 누적량만 보고 결정됩니다. 가챠포인트나 상점 구매 여부는 랭크에
영향을 주지 않습니다. 서버에 등록된 전체 랭크 단계와 필요 포인트는 누구나
`/랭크목록`으로 확인할 수 있고, `/랭크`로 본인이 다음 랭크까지 얼마나 남았는지 볼 수
있습니다.
5. `/메세지` 로 안내 임베드를 보낸 뒤, `/역할추가`로 원하는 이모지-역할을 연결하면 반응 역할 완성

`/메세지`, `/상점메세지`의 제목·내용은 여러분이 입력한 텍스트 그대로만 임베드에 들어갑니다
(버튼/반응은 별도 명령어로 나중에 연결).

## 4. GitHub + Railway 배포

1. 이 폴더를 GitHub 저장소로 push (`.env`는 절대 커밋하지 마세요, `.gitignore`에 이미 포함됨)
2. Railway → New Project → Deploy from GitHub repo 선택
3. Variables 탭에서 `DISCORD_TOKEN` 환경변수 추가
4. **DB 영구 저장(중요)**: Railway는 재배포 시 파일시스템이 초기화될 수 있습니다.
   Railway → Volumes에서 볼륨을 만들고 마운트 경로를 예: `/data`로 지정한 뒤,
   `DB_PATH` 환경변수를 `/data/bot_data.db`로 설정하면 포인트/기록이 유지됩니다.
5. Settings에서 Start Command가 자동으로 `python main.py`로 잡히지 않으면
   `Procfile`(`worker: python main.py`)을 기준으로 수동 지정해주세요.
6. 배포 후 로그에서 `로그인 완료`, `슬래시 명령어 N개 동기화 완료` 메세지를 확인하세요.
   (슬래시 명령어가 서버에 바로 안 보이면 디스코드 클라이언트 재시작 또는 몇 분 대기)

```
├── cogs/

│   ├── shop.py              # /상점역할 /상점메세지

├── utils/
│   └── image_card.py        # 통계 카드 이미지 생성
└── assets/fonts/            # 한글 폰트 (직접 추가 필요)
```

## 참고 사항

- `/음성`, `/채팅`, `/포인트`, `/추가`, `/제거`, `/상점역할`, `/상점메세지`, `/메세지`,
  `/역할추가`, `/온보딩설정` 중 관리자용 명령어는 "서버 관리" 또는 "역할 관리" 권한이 있어야 합니다.
- 상점 버튼은 `/상점메세지`로 보낼 당시 등록된 역할 기준으로 생성됩니다.
  이후 `/상점역할`로 새 역할을 추가했다면 상점 메세지를 다시 보내야 새 버튼이 반영됩니다.
  (이미 보낸 메세지의 기존 버튼은 봇 재시작 후에도 계속 정상 작동합니다)
